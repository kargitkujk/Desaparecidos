# Etiquetas de HTML

Estructura principal:

- `<!DOCTYPE html>`: Indica al navegador que el documento está escrito en HTML5.
- `<html>`: Elemento raíz que contiene todo el documento HTML.
- `<head>`: Contiene metadatos (información no visible para el usuario).
- `<meta>`: Define metadatos como la codificación de caracteres o configuración de la página.
- `<title>`: Título de la página (aparece en la pestaña del navegador).
- `<link>`: Enlaza recursos externos, como archivos CSS.
- `<style>`: Permite escribir estilos CSS dentro del documento.
- `<script>`: Permite agregar código JavaScript.
- `<body>`: Contiene todo el contenido visible de la página web.

Etiquetas semánticas:

- `<header>`: Encabezado.
- `<nav>`: Navegación.
- `<main>`: Contenido principal.
- `<section>`: Sección.
- `<article>`: Contenido independiente.
- `<aside>`: Contenido secundario.
- `<footer>`: Pie de página.

Texto y formato:

- `<p>`: Párrafo.
- `<span>`: Texto en línea.
- `<div>`: Contenedor.
- `<strong>`: Texto importante (negrita).
- `<em>`: Énfasis (cursiva).
- `<small>`: Texto pequeño.
- `<br>`: Salto de línea.
- `<hr>`: Línea horizontal.

Listas:

- `<ul>`: Lista desordenada.
- `<ol>`: Lista ordenada.
- `<li>`: Elemento de lista.
- `<dl>, <dt>, <dd>`: Lista de definiciones.

Multimedia y enlaces:

- `<a>`: Enlace.
- `<img>`: Imagen.
- `<video>`: Video.
- `<audio>`: Audio.
- `<source>`: Fuente multimedia.

Tablas:

- `<table>`: Tabla.
- `<thead>, <tbody>, <tfoot>`: Partes de la tabla.
- `<tr>`: Fila.
- `<th>`: Encabezado.
- `<td>`: Celda.

Formularios:

- `<form>`: Formulario.
- `<input>`: Campo de entrada.
- `<textarea>`: Área de texto.
- `<select>`: Lista desplegable.
- `<option>`: Opción.
- `<label>`: Etiqueta.
- `<button>`: Botón.
- `<fieldset>`: Agrupa campos.
- `<legend>`: Título del grupo.
- `<autocomplete>`: Se va llenando en las cookies
- `<required>`:Para que el campo sea obligatorio.
- `maxlength`:Para colocar maxima cantidad de characteres.
- `minlength`:Para colocaar minima cantidad de characteres.

Otros:

- `<iframe>`: Inserta otra página dentro de la web.
